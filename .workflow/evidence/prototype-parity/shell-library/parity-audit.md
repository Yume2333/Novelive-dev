# Shell, library, settings, usage and welcome parity

Prototype `prototype/src` (port 5181) against production `pnpm dev` (port 5173) with local synthetic projects and seeded usage rows (167 calls; costs set on the synthetic rows for three models, one model left unpriced to show the exclusion). Files are named `<page>-<prototype|production>-<theme>-<viewport>.png`.

| Page | Matches prototype | Production difference |
| --- | --- | --- |
| Shell | Brand, global nav, current work with cover and `series · 第 N 卷`, work switcher (projects and installed packages; picking an installed work from a project route returns to the library with that work and its play link in the sidebar), work nav, overlay Agent button, queue footer, theme switch, fixed 248px sidebar with long titles | An installed-package recent offers play only; there is no installed-overview host API |
| Library | Project/imported tabs, `project.directory` series groups with volume headings, covers, status and progress, header actions 导入作品包 and ＋ 新建工程, grid that fits 960px | No author line or attention/image counts, because `library.list` has no such fields |
| Settings | 760px width, label-cap sections, model cards summarized as model · API format · 同快速模型, empty slots shown as 未填模型, small 高级 toggle | — |
| Usage | 用量统计 title, 按天/按月 granularity, filter row (work/phase/model, date range, help tooltip), four KPI cards (calls, text tokens with input/output in the hint, images, reference amount), period bars, a work × phase table with prototype phase names and a per-work reference amount | Text volume is shown in tokens because usage records have no character count. The reference amount sums priced `costUsd` in USD; unpriced calls are left out and flagged, and a total with no priced calls reads 没有单价 |
| Welcome | `/welcome` outside the shell, all three steps in light and dark: language, create/play path, model setup (shared connection, two-column text models, image row); saved theme and language apply on direct launch | The image endpoint shows the real default `https://api.openai.com/v1` where the prototype shows a placeholder |

Welcome, Settings and Usage captures are retaken on integration `ce4c00a` (32px page title, Settings section gap, Welcome inputs, Usage per-work reflow under 1200px). `welcome-models-production-{light,dark}-1440x900.png` and `shell-package-switch-production-light-1280x800.png` are regenerated from the final Electron build by `tests/e2e/prototype-parity.spec.ts`. Shell and library captures predate those fixes.

Integration also reflows work × phase values into labeled per-work rows below 1200px so a full eight-phase record remains readable rather than wrapping table headings and currency into vertical characters. The desktop table stays unchanged. The existing creator recorders do not persist provider prices, so current real calls normally return `costUsd: null`; synthetic priced fixtures verify the optional read contract only, and production truthfully shows 没有单价 rather than estimating or inventing a price.
