# M1a/07 W4 比较口径：整卷多数共识

决定：2026-11-23，所有者委托的协调者批准。门槛仍为 0.90，schema 不放宽；分块过拆分仍须修复。

## 原因

同一 `gemini-3.8-flash` 整卷综合 prompt，在同一批首卷「奮字卷之一」7 回预览上重跑，结果彼此差异很大。以现行规范化条目 F1 计（`tests/acceptance/bible-patch-score.ts`）：

| 比较 | 条目数 | F1 |
|---|---|---|
| 整卷 A 对 整卷 B | 59 / 50 | 0.51 |
| 整卷 B 对 原整卷 | 50 / 50 | 0.60 |
| 整卷 A 对 原整卷 | 59 / 50 | 0.61 |
| temperature 0 + seed 7 两次互比 | 61 / 45 | 0.51 |

单次整卷结果自身只有约 0.5–0.6 的一致度。拿分块结果和它比，要求 F1 ≥ 0.90，测到的主要是模型噪声；分块路径怎么改都无法通过。

## 口径

固定三次整卷结果（原整卷、A、B），存为 [`tests/fixtures/m1a-owner-book/whole-runs.json`](../../../../tests/fixtures/m1a-owner-book/whole-runs.json)，只含 BiblePatch 与 GlossaryPatch：

- 参照：三次中至少两次出现的条目（逐条按现行匹配规则配对，每条只计一次）。
- 基线：每次整卷对“其余两次的共识”的 F1，取三次的平均（留一）。
- 通过：`分块对参照的 F1 ÷ 基线 ≥ 0.90`，已确认设定零丢失，重启零模型调用。

严格回放 `tests/unit/m1a-w4-gate.test.ts` 读取固定的整卷结果和最近一次录制的分块结果，不发起任何请求。

## 固定数据上的数值

参照 37 条；留一 F1 为 0.692 / 0.607 / 0.651，基线 0.650。

| 对象 | 条目数 | 对参照 F1 | 归一 |
|---|---|---|---|
| 修复前分块（PR #45 之后） | 310 | 0.184 | 0.28 |
| 第四次整卷（temperature 0，未入参照） | 61 | 0.673 | 1.04 |
| 第五次整卷（temperature 0，未入参照） | 45 | 0.659 | 1.01 |

两次没进参照的独立整卷归一后都超过 1.0，所以这个口径能让一次正常的整卷结果通过；修复前的分块结果仍然不通过。

重跑耗费（私有账本 `usage.csv`）：`gemini-3.8-flash` 5 次，79,068 tokens，0 张图；其中 1 次 12,286 tokens 的运行复用了旧检查点，没产生条目，不计入比较。
