### B4. Native scrollbars — 2 hits, both JUSTIFIED
1. `packages/ui/src/pages/bible/BiblePage.module.css:857`
   `.glossaryTableWrap { overflow-x: auto }` — horizontal scroll containment
   for a wide data `<table>`. JUSTIFIED on two grounds: (a) the kit
   `ScrollArea` is vertical-only (`overflow: hidden auto` — x locked hidden,
   custom overlay scrollbar vertical-only), so the kit cannot express
   horizontal scrolling at all; (b) the wrapper additionally carries the global
   `.nl-scroll-hidden` utility (`BibleFields.tsx:981`, `base.css:41-49` →
   `scrollbar-width:none` + webkit `display:none`), so no native scrollbar is
   ever painted. Surface: pages/bible.
2. `packages/ui/src/panels/agent/MessageView.module.css:198`
   `.code { overflow-x: auto; …; scrollbar-width: none }` — horizontal
   containment inside a `<pre>` code block (with `pre-wrap`+`overflow-wrap:
   anywhere` so it rarely even overflows); the native scrollbar is explicitly
   suppressed by `scrollbar-width: none` in the same rule. JUSTIFIED.
   Surface: panels/agent.
