# M5 Linux native acceptance

- Host: Ubuntu 22.04.5 LTS x64, Electron 45.4.1.
- Unsigned build: `pnpm --filter @novelive/desktop run package:linux` produced Novelive 0.0.0 and `latest-linux.yml` under `apps/desktop/dist/linux-x64-rHTZAu/artifacts/` (local only). Both passed `sha256sum -c SHA256SUMS`. AppImage SHA-256: `66fe372d1d71b81efbf35fa95cf87fdd7741a6af52a8158a96305b9ca65a32ac`. The packaged resources include `LICENSE.txt` and `THIRD_PARTY_NOTICES.txt`.
- AppImage launch and GTK Chinese font check passed on this host. A preliminary build (`linux-x64-UR8d12`, also 0.0.0) launched with `APPIMAGE_EXTRACT_AND_RUN=1` and a fresh profile; its [library](appimage-library.png) rendered and its actual GTK [file chooser](appimage-gtk-cjk.png) displayed the Chinese characters in “Novelive 作品包” rather than boxes.
- The GTK chooser uses the OS fonts, not the web fonts bundled in the renderer. This machine initially lacked Noto CJK. Install the distro's `fonts-noto-cjk` package (Ubuntu/Debian), or extract its fonts to `~/.local/share/fonts/`, run `fc-cache -f`, and relaunch the app. This is a host prerequisite, not a font bundled by the AppImage. The no-font reproduction was not repeated.
- Packaged application share and play passed: `NL_M5_EXECUTABLE=<build>/linux-unpacked/novelive NL_REPLAY=strict pnpm exec playwright test --grep 'M5 share and play offline'`. Screenshots: [export warning](export-warning.png), [open package](open-package.png), [offline playback after deleting the original archive](offline-playback.png), [package update review](update-review.png). This replay uses synthetic content, temporary profiles and an executable argument to open `.novelive`; it verifies the packaged app's argument handling, not the desktop file-manager association.
- The AppImage wrapper itself remains unverified for the complete replay: Playwright targeting the AppImage directly hit the 150-second test timeout before reaching the first screenshot. The working packaged executable is the unpacked payload, not the wrapper.
- Native desktop-file integration and OS double-click are unverified: no AppImage desktop integration was installed on the test host.
- Native packaged four-language visual review is unverified. The development Electron replay switched and persisted all four locales, but it did not run against the package.
- AppImage download/relaunch on a newer release is unverified: only one local release version was available. The Linux deb manual-download behavior is unverified natively; M5 does not produce a deb artifact.
