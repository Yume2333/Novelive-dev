## 透明底接口探测

- 离线捕获实际适配层请求：`/v1/images/generations` 的 JSON 和 `/v1/images/edits` 的 multipart 均发送 `background=transparent` 和 `output_format=png`，编辑请求携带一张 PNG 参考图。
- 通过同一中继用 GPT Image 2.6 Sunburst 探测两次（无参考生成、单参考编辑）。两次均返回 HTTP 200 和带 alpha 的原始 `b64_json` PNG；alpha 小于 16 的像素分别占 63.8% 和 75.6%，适配层返回字节与原始图片字节一致。单参考编辑未丢失 alpha，未探测 Flare。
- 上述探测不能复现项目原出图请求的失败，也不说明该失败的上游原因。未改产品代码，未重开 Electron 制作；仍为 0/7 章发布。
