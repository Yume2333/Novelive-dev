### Verdicts

- packages/ui/src/pages/editor/EditorPage.tsx:95 — `params.get('chapterId') ?? 'ch0001'`

  (`workChapters[0]?.chapterId`), not a hardcoded internal id. Owner: 04-editor.

- packages/ui/src/pages/editor/diagnostics.ts:23 — doc comment `/** p0007 形的原文段落 id。 */`
  JUSTIFIED: comment only, never rendered. The actual runtime path (line 117-121, `humanizeIds`) converts `pNNNN` → `formatParagraphLabel` ordinal text.

- packages/ui/src/pages/editor/directive-display.ts:62,90 — comments `p0001, p0003` / `p0001-p0005`
  JUSTIFIED: comments only. Runtime parses these tokens into ordinals via `formatParagraphLabel`/`formatParagraphRange` (lines 55-68);
