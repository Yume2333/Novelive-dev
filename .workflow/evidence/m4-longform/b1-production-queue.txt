B1 — series handoff and global production queue

Creator: one shared series preparation per project, in persisted volume order.
Each onReady resolves that volume's waiting sessions and opens all its works;
it does not await candidate generation or later volumes. Persisted chapter
state skips already-started volumes on restart; preview/synthesis checkpoints
resume unfinished volumes. Appended volumes start another shared pass after
the previous pass, skipping started volumes. Preparation is aborted on close.
Synthesis usage stays attributed to the volume's first work.

Queue: typed production.getQueue and production.moveQueueWork commands use
the existing service/WorkQueue. AppShell sidebar status opens a modal drawer
with ScrollArea and ProductionQueuePanel. App-scope queue events update it;
mount, opening, creator.ready and reconnect refetch the queue. Stop/continue
reuse existing commands. Paused reasons include 异常退出后已暂停.
