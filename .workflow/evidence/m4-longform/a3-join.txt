Slice A3: append an imported book to an existing series

The import UI offers New Project / Join Existing Series, uses the existing
folder picker, and queries import.target to validate the selected Novelive
project and show its series. Projects currently contain one series.

import.file accepts join: { projectDir, seriesId }. All five formats share
the extraction path, then joinSeries appends each extracted volume in order.
Each joined volume saves its original under source/imports/<volumeId>/.
All new work IDs are registered. Existing settings are inherited by new
works, while existing bible/settings/source files remain byte-identical.
Joined imports do not use the empty-project layout writer. A stale original
wizard cannot revise away volumes appended by a later join.

Illustration selection and adding external references remain new-project-only.
Joins retain existing project references; their import report is not replaced.
The UI shows the added volume titles/chapter counts and links to the new work.
