## Wiring choices

- Reuse production `rewriteScene` / `redraw` / `adoptImage` / `redo` through
  `CreativeRevisions` for both editor commands and Agent proposals. Resolve the
  current production session when a worker method runs, so cached chat sessions
  do not retain a production session closed by switching works. Copy redraw
  candidates to content-addressed application-cache paths before returning them.
- Keep the existing editor route, player and token-based CJK/scrollbar styles;
  expose the route in work navigation and pass current scene context to Agent.
- Keep gate chat/worker recording separate from earlier fixtures. Opt-in request
  identity normalization handles generated UUIDs and NVS line IDs without
  altering responses; legacy production fixtures retain their original hashes.
- The current editor backend produces no mark suggestions. `editor.resolveMark`
  is registered and version-checks before returning `not_found`; it does not
  invent a mark-suggestion producer outside this gate's scope.
