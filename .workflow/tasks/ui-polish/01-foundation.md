**Effort:** ui-polish
**Blocked by:** None
**Covers:** W1, W2
**Files:** packages/creator/src/ (contract, models/text, scheduler/chapter, project/production.ts, import/, chat/), packages/ui/src/format/ (new), packages/ui/src/components/, packages/ui/src/styles/, packages/ui/src/i18n/, packages/ui/src/locales/*/{components,format}.json, DESIGN.md, tests/unit/; mechanical call-site updates only in pages/shell/panels for the cutovers below
**Read first:** .workflow/specs/ui-polish.md, .workflow/research/ui-polish-audit.md (every "Shared fixes" list), DESIGN.md, docs/ux.md
**Check:** `NL_REPLAY=strict pnpm check && pnpm build` → typecheck, Biome, Stylelint, all unit tests (new format/error tests, creator tests, locale parity), and desktop build pass.

- [ ] **Creator contract error kinds.** Export `issueKinds` from `@novelive/creator/contract`. It covers every model error code (`network`, `auth`, `not_found`, `moderation`, `invalid_config`, `reasoning_limit`, `cancelled`, `internal`), every scheduler `errorType` (`budget_paused`, `portrait_framing`, `matting_unavailable`, and any others in `scheduler/chapter/`), and `unknown`. The production snapshot's chapter `issue` becomes `{ kind, detail? }`. `production.chapterRecord` drops the hardcoded zh-CN `message` and replaces the raw-enum `detail` with `errorKind?` plus an optional raw `detail`. Classify at the source: no regex over formatted `[code] …` strings in the UI.
- [ ] **Import and project error codes.** Every error thrown under `packages/creator/src/import/` that reaches the UI (EPUB/DOCX/PDF/Markdown/TXT limits, DOCTYPE, non-empty project, illustration mismatch, encoding) gets a contract `importErrorCodes` entry and is surfaced as a command error with that code. Existing `projectErrorCodes` stay. Share/export command errors expose their code if they don't already.
- [ ] **Chat subtask label.** The subtask part carries the delegated `task` text (trimmed to one line) as `label` and the role as a separate `role` field. Proposal tool results stay model-facing and unchanged.
- [ ] Update creator unit tests and any `tests/unit` contract tests for the new shapes; replay cassettes must keep passing untouched.
- [ ] **`packages/ui/src/format/`**: `chapter.ts` (`formatChapterLabel`, numeral, range, `formatParagraphLabel` from `pNNNN`, `formatVolumeLabel`, `formatSceneLabel` ordinal; no function ever returns a raw id), `language.ts` (move the language-name table out of `ImportPage.tsx`), `path.ts` (home-collapse + middle ellipsis; get the home directory from the existing host/app snapshot, or add it there if absent), `cost.ts` (`formatCost`: cents, `< $0.01` floor), `work.ts` (`useWorkTitles` / `formatWorkTitle` with an `已删除的作品` fallback), `asset.ts` (move `backgroundLabel`/`portraitLabel` from `pages/editor/scene-assets.ts` and generalize: asset key → bible names + costume/expression/variant description → humanized slug fallback; one separator convention), `errors.ts` (`humanizeError(kind | code | Error)` → `{ message, hint?, detail? }` covering every `issueKinds`, `projectErrorCodes`, `importErrorCodes`, share and config code, with a generic fallback).
- [ ] **Shared components**: `ErrorNotice` (error `Banner` + optional retry + collapsed `Details` for raw detail), `LoadingState`, `Details` (default-collapsed 「详细信息」 disclosure, mono body), and `ButtonLink` (router `Link` with the exact `nl-btn` variant and size classes). `PageAction` renders through `ButtonLink`. Remove `Page`'s `action` alias and migrate callers to `actions`. Delete the `inputStyle`/`textareaStyle` JS objects, move their styling into CSS, and migrate callers. Make `EmptyState` the single empty pattern (icon, optional title, text, optional action, `card`).
- [ ] **Type scale**: add font-size tokens to `styles/tokens.css` (integer steps only, e.g. 11/12/13/14/16/18/22/28) and document them in `DESIGN.md` 「排版」. Fix the `components/` and `styles/` sites. Pages are fixed by their surface tasks.
- [ ] Register a `format` i18n namespace; add all new strings to `zh-CN`, `zh-TW`, `en`, `ja` (`format.json`, `components.json`).
- [ ] Unit tests: chapter/paragraph/volume formatting including miss fallbacks, path collapse, cost rounding, asset label fallbacks, `humanizeError` returns a non-raw message for every exported kind/code, creator classification of model and scheduler failures into `issueKinds`.
- [ ] Call-site updates outside the owned folders are limited to compiling the new shapes and APIs (for example `issue.detail ?? ''` → `humanizeError(issue.kind).message`). Redesign belongs to tasks 02–07.
