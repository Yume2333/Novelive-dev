- **整卷漏提取**：完成的整卷请求装入了全部 7 章已存预览（预览共 23,605 字节，未装入小说原文）；7 章均有进展输出。响应正常结束（`finish_reason=stop`），报告 3,571 个输出 token，请求上限为 48,000。证据不支持输出截断或漏装整章；旧提示只要求整卷综合与逐章进展，未要求逐章穷举符合条件的条目。预览本身是否漏掉原文细节未验证。
- **分块重复及粒度差异**：比对中有 15 条重复 ID 的新增行（14 人物、1 关系），另有 4 组同名不同 ID（人物、地点）。重复不能解释全部差距，尤其是时间线、伏笔和术语的缺口。已要求整卷返回逐章条目并集、分块只报符合条件的新事实；发布时合并已接受的重复新增条目，保留人物别名并重映射关联，同时不合并已有 ID 或原名冲突的实体。
- **修正后的一次付费重跑未完成**：`gemini-3.8-flash` 复用预览，发出 3 次综合请求（0 次预览、0 张图）；总计 43,167 token，其中 28,696 为实测、14,471 为一次未完成请求的保守预留，低于 500 万上限。分块只存下一个事件就返回 `[cancelled]`，未发布分块结果，也未运行整卷对照、确认设定检查或重开检查。最后一次请求的具体中止原因未证实；本次没有新的 F1，表中最后一列不能用作对照分数。已停止付费，W4 保持开放，未启动 M1b/11。
- **中止诊断及修复**：旧日志记录测试约 285 秒时退出，低于 Vitest 的 1,200 秒上限，且没有 hook 超时。账本最后一次请求仅有保守预留，旧测试捕获底层异常后直接中止整轮，未留下可区分 SDK 超时与中转断开的信息。用同一 SDK 离线模拟慢响应，旧测试先读完响应体才交给 SDK，触发传输时限；流式返回后，同一响应正常结束。现将用量核算移出响应路径，分别记录响应头与响应体阶段的失败；时限按输出 token 上限和实测速率保守估算。断点来自已经更改指纹的版本，离线截获首条请求确认从第 1 包、已提取 1 个事件继续，未发出实际请求。

### M3/07 · W3：Linux Vulkan 放大性能

仍需在配有 GPU 的 Linux Vulkan 参考机上实测 1024px→2K：默认动漫档预热后 P95（门槛 20 秒）及双次耗时。本次 VM 只有 llvmpipe（CPU Vulkan），实测关闭 0.336 秒、快速档单次 121.066 秒（见 [Linux 试安装证据](evidence/m3/linux-trial.md)）。
