# Glossary

Shared project terms—one entry per concept so code, specs, and UI use the same words. Configured with git union merge.

## Format

Every entry under `## Terms` is a bullet list item:

```markdown
- **Term**: one-sentence meaning and where it lives in code.
- _Avoid_: competing synonyms not to use (optional; omit when none exist).
```
<!-- workflow:end -->

## Terms

- **作品（work）**：一部可玩的视觉小说，含若干章节；层级为 系列（series）→ 卷（volume）→ 作品 → 章节（chapter）。
- **工程（project）**：创作端的一个文件夹，含解包后的作品和创作专用数据（原文、任务记录、候选图、对话记录、用量记录）；拷走文件夹就能换机器。
- **作品包（package）**：导出的 `.novelive` ZIP 文件，可游玩，也可导入为新工程。
- _Avoid_: 项目包、工作区
- **场景（scene）**：剧本的组成单位，Agent 重写的单位，一个场景一个 `.nvs` 文件。
- **剧本**：用文本剧本语言写的语义化场景描述，作品格式的主体，播放器加载时解析并编译。
- **指令**：剧本里以 `@` 开头的演出行，写意图，参数可选。
- **行内标签**：一句话里的 `{…}` 标记，写文本标记、注音、停顿和变速。
- **句子 ID**：应用分配、写在行尾的随机短 ID（4 位小写十六进制，如 `#a3f9`），内容改了也不变，存档和已读靠它迁移。
- **素材名 / 素材 ID**：角色、造型、表情、地点、变体、CG 的可读英文名，如 `lin-xiao/uniform/angry`，创建后不改。
- **素材登记表**：`assets/asset-registry.json`，登记全部舞台素材的 ID、类型、文件路径、状态（已画 / 待画 / 占位）和同义别名；写手、美术导演、画师、编译器、播放器只认这张表的 ID，说话人 ID 另查设定集角色表。
- **设定集（Bible）**：角色、角色关系、地点、剧情骨架、时间线、伏笔、风格；按卷综合产出，新条目先作为候选。字段见 `docs/bible.md`。
- **术语表（glossary）**：角色名、地名以外的专名，记原文写法、作品里的写法、注音、类别、备注。
- **变化**：设定集条目里“从第几章起、哪个字段变成什么”的列表；模型写第 N 章时只拿到截至第 N 章的设定。
- **全书预览结果**：逐章的摘要、人物、地点、线索和伏笔，存在 `source/preview/`；默认不进 `.novelive` 作品包，仅在导出时勾选带原文才随原文一并导出。
- **规则**：创作者确认的改编约束，作用域为本章或本作品。
- **改编要求**：作品级自由文本指令。
- **改编强度**：作品级预设，三档 忠实 / 平衡（默认）/ 精简；数值定义（目标句长与段落压缩量）见 `docs/creation-pipeline.md`，长度检查见 `docs/work-format.md`。
- **确认点**：自动制作中停下等创作者确认的节点，只有两个：角色设定/主视觉、第一章成品。
- _Avoid_: 检查点（播放器概念）
- **确认卡**：Agent 提出的修改或要发起的工作流，先以卡片列出给创作者确认后才生效。
- **提议（proposal）**：Agent 提出的待确认修改或工作流，存 `project.db` 提议表，界面上以确认卡展示。
- **图清单**：美术导演列出的本章要用的图，每项含素材名、类型、是否已有、一句描述、派生自哪张基准图；要新画的项进入出图队列。
- **出图队列**：按素材排的待画图队列，同一张图只画一次，基准图画完它的差分才开始画，同时画的图不超过「同时出图数」。
- **同时出图数**：图片模型设置项，默认 8，限制同时画的图。
- **生图失败重试次数**：图片模型设置项，默认 3，一张图在技术检查或视觉审核不通过后最多重画几次，用完用占位图并标“需要处理”。
- **录制回放**：基于 `registerFauxProvider` 假模型与 fetch 注入的测试回放层，按录制文件回放真实接口的流式响应和错误，可注入取消、截断、断线；录制文件去掉 Key 和中转地址后进仓库。
- **安全区**：背景和 CG 画面中间的 4:3 区域，主体落在里面；各种横屏比例铺满裁切时主体不受影响。
- **章附注**：导入时从正文剔除的注释、脚注、版权页等非正文段，存 `source/chapters/<章节 ID>.notes.txt`；不参与段落覆盖，也不进剧本。
- **作品设置**：每部作品的设置项，存 `work.json`：改编强度、演出密度、改编要求、规则、写手预设选用、审稿开关、确认点 1 开关、自定义标记、输出分辨率、作品主色；`work.json` 另存 `workId`、`version`、`derivedFrom`、`minReaderVersion`、`appVersion`（字段见 `docs/work-format.md`）。
- **子 Agent**：界面上叫“子任务”；只有对话面板里的主控能派，子 Agent 不能再派。
- **运行记录**：一次制作任务或会话的过程记录（消息、思考、工具调用、结果），存 `project.db`；制作面板点开某一章可查看。
- **全书预览 / 综合**：逐章摘要；按卷汇总成剧情骨架、设定集、术语表。
- **快速模型 / 主模型 / 写作模型 / 视觉模型 / 图片模型**：五个模型配置。
- _Avoid_: 创作模型（已拆成主模型和写作模型）
- **Agent 角色**：整理（快速模型）、主控（主模型）、写手（写作模型）、审稿（主模型；忠实度检查默认开、文风审稿默认关，两档都关时这一步跳过）、美术导演（主模型）、立绘画师（主模型）、场景画师（主模型）、差分画师（快速模型）、视觉审核（视觉模型），共九个。“角色”单说时指故事人物，指 Agent 角色要说全。
- **写手预设**：写手的文风说明、输出约束、采样参数和输出替换规则；全局默认，作品可改选。
- **会话**：对话面板里的一串聊天，可分支、可压缩。
- **Novelive Agent**：应用内的创作 Agent，中英文界面同名，上下文明确时简称 Agent。
- _Avoid_: AstraLoom、创作助手、AI 助手
- **Agent 底座**：pi（`@earendil-works/pi-ai`、`@earendil-works/pi-agent-core`），直接嵌在创作端进程中。
- **主视觉**：一张风格基准图加关联设定描述，存 `assets/style/main-visual.webp`。
- **素材层级**：角色 → 造型 → 表情；地点 → 变体；CG 为单独一类素材（同一系列可逐级共享和覆盖，见 `docs/visuals.md`）。
- **需要处理（标记）**：挂在章上的标记，不是状态；章失败或用了占位图时打上，等创作者处理，处理完去掉。占位图章的状态仍是“已发布”。
- **过期**：上游设定或参考变化后，图片待创作者决定是否重做的标记。
- **红线**：写在改编要求里的可检查断言，违反即整章作废，内容人工必审。
- **降敏**：内容审核拒绝后去具象词改写一次的规则；写手整章改写一次，画师改提示词一次。
- **槽位**：立绘位置槽，left / center / right 枚举。
- **占位图**：内置的三类降级用图：角色、背景、CG；图片最终失败的章用它发布。
- **工作流**：确认卡发起的一条后端任务，如重做章节、重写场景、重画图片、重新综合某卷。
- **设定补丁（BiblePatch）**：按卷综合产出的设定集增量更新，全量操作为新增、更新、删除、不变；删除仅用于单卷综合修正错误条目，加入已有系列时只用新增、更新、不变（不删系列已有条目）。
- **用量统计面板**：Token、图片次数与参考金额的统计界面，只作参考。
- **文本类型**：对白、内心独白、旁白、字幕。
- **文本标记**：一句话里局部文字的效果；内置七种，作品可以自定义。
- **注音**：标在字上方的读音或原名。
- **演出密度**：作品级预设，三档 宽松 / 标准（默认）/ 激进，控制演出指令的密集程度（存 `work.json`）。
- **基准图 / 派生图**：造型基准图和地点基准图是按描述独立绘制的母图；表情差分和背景变体从对应基准图编辑派生，只改一处且像素尺寸与基准图一致。
- **同义表情合并**：美术导演列图清单时将未登记表情与已有表情比对，意思相同则归并复用已有表情，归并别名登记在 `assets/asset-registry.json`。
- **制作槽**：全局唯一并发制作席位（同一时间只制作一部作品的章管线与出图）；停在确认点时让出制作槽，确认后排回队首，全书预览与按卷综合不占制作槽。
- **全局制作状态**：应用级队列状态词，固定为 `空闲` / `制作中` / `已停止` / `待确认`（显示于侧边栏底部）。
- **章节状态**：面向用户的章节进度词，固定为 `已发布` / `制作中` / `等待`；`需要处理` 为独立挂在章上的标记，不属状态枚举。
- **技术检查**：生图工具内的确定性校验，检查解码、派生图尺寸与 alpha 外框、CG/背景 4:3 安全区占比（≥ 0.70）以及透明底有效性（alpha 通道与棋盘格像素检查）。
- **视觉审核**：视觉模型在生图工具内对照参考图和描述的判图步骤，输出 `{pass, failedChecks, feedback}`，分项检查 `identity`、`anchors`、`description`、`style`、`artifacts`。
- **剧本检查 / 局部修复**：解析器校验剧本文本、素材引用与原文段落范围，代码自动修复机械格式问题（如 BOM、代码块围栏、换行），未登记素材或越界范围仅退回对应场景给写手重写。
- **锚点特征（anchorFeatures）**：角色外貌中的 2–3 个强辨识细节（如痣、发饰、瞳色），确认点 1 定稿时写入设定集，供派生图“其余保持”清单和视觉审核 `anchors` 核对。
- **主色（keyColors）**：角色外貌中的发色、瞳色与主要服装颜色短语，供颜色锁定句和视觉审核 `anchors` 核对。
- **颜色锁定句**：画风固定句前紧接的英文短句，将出场角色 `keyColors` 写入提示词末端以防画风参考串色（立绘与 CG 使用）。
- **画风参考 / 补充参考**：统一画风用的参考图组，含 `assets/style/main-visual.webp`（主视觉 1 张）及最多 2 张同画风不同角色的补充参考，路径与风格描述记于 `bible/style.json`。
- **画风固定句**：拼接在生图提示词最后一行的英文常量（`creator` 包内定义），用于约束成稿线稿、细节主次、线条收尾与表面纹理。
- **后处理**：生图结果缩放到目标尺寸前的放大降噪，三档：关（sharp Lanczos 直接缩放，不降噪）/ 放大降噪（默认，跑一遍 Real-ESRGAN）/ 双重放大降噪（跑一遍、缩回原尺寸、再跑一遍）；放大档位默认 `realesrgan-x4plus-anime`，快速档 `realesr-animevideov3`。
- **原生长边上限**：图片模型配置项，档位 1536（Codex 渠道，默认）/ 2048 / 2560（OpenAI 官方 API）/ 2816（Seedream 5.x）/ 3840（4K：OpenAI 官方 API 实验性、Seedream 4.5 / 5.0 lite），限制发往生图接口的请求长边，超出目标分辨率的部分由本地后处理放大；低于接口像素下限时向上吸附。
- **能力不支持错误**：制作时用到编辑、透明底或某个尺寸而图片接口不支持（拒绝请求，或要求透明底却返回无 alpha 通道的图）；不重试，整部作品暂停并报错。图片模型能力不由用户声明。
- **可知性边界**：写手提示词与上下文渲染约束，确保作者视角的全卷骨架不转化为角色提前知晓的秘密或过早揭晓的伏笔。
- **第几章揭示（revealedChapter）**：设定集条目字段，标记读者最早知晓该设定的章节（未填按首次出场算），写第 N 章时仅提供已揭示的条目。
- **放大程序**：负责模型放大与降噪的 ncnn-vulkan 可执行文件（`upscayl-bin`），由创作端通过临时文件与标准输入输出调用（资源目录 `bin/upscale/`）。
- **重看**：玩家从章节目录打开已读过章节时的状态，不修改主线进度。
- **生成预览流**：OpenAI images 接口的流式部分出图预览（`stream` / partial image streaming），第一版默认不开启。
