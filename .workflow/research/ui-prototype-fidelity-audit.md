# UI Prototype Fidelity Audit

Verified gap inventory comparing `prototype/src/` against `packages/ui/src/` at `07e73ea` (2026-11-25). Every item below was confirmed by reading both trees and comparing rendered screenshots in `.workflow/evidence/prototype-parity/`.

## 1. Global Styles & Primitives (`prototype/src/styles/` & `prototype/src/components/`)

### Styles regressions (`packages/ui/src/styles/`)
- `shell.css`: `body` lost `background-attachment: fixed` and `-webkit-font-smoothing: antialiased`; added a generic `:focus-visible { outline: 2px solid var(--color-outline) }` that overrides prototype's softer `--accent-border-35` / `--shadow-focus` focus language on `select`, `textarea`, and generic focusables.
- `base.css`: dropped `!important` on input `:focus` (`background: var(--white-90)`, `box-shadow: var(--shadow-focus)`) and on `.nl-btn-primary:hover`, `.nl-btn-ghost:hover`, `.nl-nav-item[data-active='false']:hover`, `.nl-card-interactive:hover`, allowing page-scoped CSS modules to clobber glass focus and hover feedback.
- `tokens.css`: missing `--cover-author` token for `GradientCover` author typography.
- `ScrollArea.module.css`: track lost `z-index: 6`, lost `.host:focus-within > .track[data-active="true"]` reveal, and thumb lost `4px -> 5px` hover/drag width transition.
- `AppShell.module.css` & `GlobalProductionQueue.module.css`: hand-rolled glass panels omit `-webkit-backdrop-filter`.

### Missing or downgraded components (`packages/ui/src/components/`)
- **`Motion.tsx`**: `usePresence` completely missing (zero exit animations across Dropdown, Modal, Drawer, AgentPanel, Toast; `drawer-out`/`scrim-out`/`fade-down-out` keyframes are dead).
- **`Toast.tsx`**: `ToastProvider` and `useToast` completely missing.
- **`Modal.tsx`**: portaled glass `Modal` (`--veil-95`, `radius-2xl`, blurred scrim, `usePresence` enter/exit, click-outside + Escape close, close `IconButton`, `ScrollArea` body, footer bar) missing. `ShareDialog` and page dialogs fall back to unstyled native `<dialog>`. `Dropdown` lacks `usePresence` exit animation.
- **`Form.tsx`**: `Field`, `inputStyle`, `textareaStyle`, `TextInput`, `Textarea`, `Select`, `CompactSelect` (custom chevron + `appearance: none` + glass surface), `TierPicker`, `Toggle` (custom sliding pill switch) all missing; pages render raw native `<select>`, `<input type="checkbox">`, `<input type="radio">` with divergent borders (`--accent-border-20` + `--white-55` instead of `--white-80` + `--white-60` + `--shadow-glass`).
- **`Extended.tsx`**: `Banner`, clickable `Chip`, generic portaled `Tooltip` (wrapping arbitrary triggers), `Checkbox` (using `.nl-check-input`/`.nl-check-box`), `RadioGroup`, `Slider` (with suffix readout), `SearchInput`, `Skeleton`, `Stepper`, `Drawer` (portaled right-side glass drawer with scrim + blur + `drawer-in/out`), `ConfirmDialog`, `Pagination` all missing.
- **`Button.tsx` / `IconButton.tsx`**: `Spinner` not exported; `IconButton` lost independent `iconSize` prop and shrunk default 34 -> 32.
- **`Card.tsx`**: `Card` lost automatic `nl-card-interactive` + `role="button"` + keyboard Enter/Space when `onClick` is passed; `StatusPill`, `ChapterStatusMark`, `statusMeta`, `attentionMeta` missing.
- **`GradientCover.tsx`**: lost `author` line, `style` prop, lighthouse motif, and explicit gradient/motif override.

## 2. Shell (`packages/ui/src/shell/`)
- `AppShell`: work nav shows all 5 authoring tabs even for imported read-only packages (prototype filters non-project works to 概览/游玩 and hides Agent button); selecting an installed package in the switcher jumps to `/` instead of the work; no Escape handler to exit fullscreen-then-close AgentPanel; AgentPanel unmounts immediately without `usePresence` `drawer-out`; `ScrollArea` remounts via `key={i18n.language + ':' + pathname}` instead of scrolling to top on pathname change; theme switch buttons stay disabled until backend config loads.
- `GlobalProductionQueue`: single `Workflow` icon for all 4 global states instead of per-status icons; loses chapter-level progress detail (`作品 · 第 N 章`); renders native `<dialog>` with no animation/blur instead of `Drawer`; no global stop confirmation (`ConfirmDialog`).

## 3. Global Pages (`welcome`, `library`, `usage`, `settings`)
- **Welcome**: test-connection errors render bare `<p role="alert">` instead of styled error chip with icon; title help icon uses native `title` attribute instead of `Tooltip`; playback notice lacks `Banner`.
- **Library**: flat `已发布 X/Y 章` line loses per-phase status (`全书预览中`/`等你确认角色设定`/`第一章等你过目`/`已发布 X/Y · N 需处理`/`全部已发布`), confirm-point & version `Chip`s, `ProgressBar active` sheen & step/reading progress, per-card `Dropdown` menu + `ConfirmDialog`, series icon/primary styling, icon on 导入作品包 button, two-CTA `EmptyState`, and rich `Modal` for `ImportPackage`.
- **Usage**: bar chart uses native browser `title` attribute instead of portaled glass hover/focus tooltip; filter & granularity selects are bare native `<select>` without custom chevron; date inputs lack glass shadow.
- **Settings**: all selects are bare native `<select>`; inherit toggle is raw `<input type="checkbox">`; writer preset rows lack `.hover-row` action reveal, duplicate/delete actions, and `ConfirmDialog`; `WriterPresetEditor` is an inline form instead of `Modal`; About links lack external-link icons and in-app license `Modal` view; no `useToast` feedback on save/copy/delete.

## 4. Authoring Pages (`import`, `work`, `confirm`, `production`)
- **Import**: raw `<input type="radio">` and bare `<select>`; FileRow missing file size/state/hover-remove; volume/chapter split/merge lacks tooltip icon buttons and chapter-boundary nudge buttons; step 2/3 missing `TierPicker` / adaptation settings layout structure where supported.
- **Work**: hero renders a flat gradient + `BookOpen` icon instead of `GradientCover` (168x224); hero omits author/language/reading progress; `PhaseCard` collapses 4 phases into one flat card losing current chapter/step/attention count; missing 作品设置 `Drawer` (for real workSettings, custom marks, and rules); chapter rows omit click-to-play, hover play button, `ChapterStatusMark`, priority chip, stale indicator, step/issue text; pagination uses bare numbered buttons instead of `Pagination`; `ExportPackage` uses raw radios/checkboxes and `<dialog>` instead of `Modal`/`RadioGroup`/`Checkbox`/`Banner`.
- **ConfirmVisual / ConfirmFirst**: candidate cards lack corner check badge + version pill; missing hover zoom button + `Modal` lightbox; missing per-outfit `SectionLabel` grouping and "更多" `Dropdown` menu; ConfirmFirst omits language pair caption when present.
- **Production**: 4-step pipeline uses plain underlined text instead of `ink-shimmer` + 2px underline bar + step weight contrast + fraction text; 立即停止 lacks `ConfirmDialog`; attention `Banner` lacks retry-all action; missing crash-recovery `Banner`; missing 过期图片 `Drawer`; `ChapterRecords` is a flat inline `<ol>` with `<details>` instead of a structured `RunRecord` `Drawer` with numbered step cards & tool cards; missing `等上一章` chip and hover-row priority dropdown.

## 5. Workbench Pages (`editor`, `bible`, `player`, `agent`)
- **Editor**: stage is blank until preview is clicked (no live static stage with background, cast silhouettes, speaking highlight, scene title chip, `n / total` chip, dialogue/caption box); preview has no floating 暂停/继续/停止 pill or Esc-to-stop; no prev/next line chevrons; stage footer jams a raw dark bar with bare asset-ID `<select>` and floating bottom buttons (`修改历史`/`规则`) instead of prototype's clean dark footer (`背景 · ...` / `立绘 · ...` + Dropdown split button + candidate picker `Modal`) and toolbar `...` Dropdown (`Drawer` for 修改历史, `Modal` for 存为规则); rewrite dialog uses native `<dialog>`, native checkboxes, and raw NVS dumps instead of `Modal`, `Checkbox`, and rich-text diff; no per-line hover "问 Agent" action or ArrowUp/Down navigation; no per-paragraph "让 Agent 按这段修改" or line jump in SourcePanel; deep-link `?chapterId&sceneId&lineId` drops `sceneId` and `lineId`.
- **Bible**: read-only generic field dump; missing chapter-cutoff `Slider`, `CharacterAvatar` gradients, outfit/expression visual gallery (with real resolved asset thumbs + dashed empty cards + `Modal` lightbox), location visual cards, A ⇄ B relation cards, icon-led timeline/foreshadowing rows, style reference gallery, `Drawer` for candidates/conflicts, responsive `@container` layout queries, and `CompactSelect` volume switcher (currently a raw text `<input>` for volume ID).
- **Player**: missing mouse-wheel rollback/advance, PageUp/PageDown shortcuts, entry black veil, `重看` badge, next-glyph bobbing chevron, quick-save slot card & line excerpt in Save/Load, chapter thumbnails, work title & exit `ConfirmDialog` in system menu, `finale`/`nextReady`/`waitEnd` (`ProgressBar`) overlays, paper dialogue inner highlight & noise texture, `Slider`/`Toggle` controls.
- **AgentPanel**: expand button hidden until capped, no smooth height transition or Escape-collapse; missing detachable `附带：{context}` chip; image thumbs missing `.nl-img-thumb-mask` hover zoom icon; lightbox uses native `<dialog>` without title; `ThinkingBlock` lacks live timer & `ink-shimmer`; `ToolCard` dumps raw JSON `<pre>` instead of structured args/checks/error styling; `SubtaskCard` flattened to single row; missing streaming shimmer bubble + caret; `ConfirmCard` lacks icon+chip header, general before/after diff, and destructive `ConfirmDialog`; `SummaryDivider` uses raw `<details>`.
