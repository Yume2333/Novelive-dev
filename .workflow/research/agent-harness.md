## 待讨论的建议（2026-11-20 全面整理时提出，所有者还没表态）

- [ ] **录制回放的假服务**（M0 起）：在模型接入的边界录下流式事件、延迟和错误，测试里回放；可以注入取消、截断、坏图、断线，CI 不需要 Key 也能复现整章的故障。
- [ ] **剧本检查与局部修复**（M1a）：解析器输出带错误码和位置的诊断，先由代码处理代码块围栏、BOM、换行这类机械问题，再检查原文段落越界、素材名不存在、句子 ID 重复；剩下的问题只把出错的那一场交回写手改，不整章重写。
- [ ] **质量评测集**（M1b 起）：从测试用书里挑出别名、章内揭晓、跨卷伏笔、换装、超长章、专名译法这几类片段，人工标好必须保留的情节和应该用到的图；改提示词或换模型时重跑对比。
- [ ] **确认点 1 只要第一卷的主要角色**（M1b）：其余角色第一次出场时再出设定图，避免长书在第一章之前就要出几十个角色的候选图。
- [ ] **同义表情合并**（M1b）：写手用了新表情名时，先看已有表情里有没有意思相同的（如 `smile` 和 `happy`），有就映射过去，少画一张。
- [ ] **设定条目记来源段落**（M2）：候选条目记下从哪几段原文提取；创作者改错一条设定时，能列出用到它的场景和图片。
- [ ] **美术导演按场景分批**（M1b）：章太长时整章剧本一次放不下，按场景分批补演出。已记在 `agent-orchestration.md` 的 Open questions。
