## 变体定义

## 我的目检（contact/ 与 gen/ 原图，`?q=` 视觉检查）

- s1：V0 雨街水光、车条辐、发丝高光都很碎很"AI"；V1 同构图下远景糊化、色块大、人物与车读得更整。V4 介于 V2/V3 之间，仍偏 concept-art 油光。
- s2：V1 明显最"赛璐璐平涂"——砖缝、落叶、电线密度大降，阴影成大块斜形；V2/V3 把灰砖缝、青花瓷纹路都画得很细（spec 里"grey-brick shopfronts"被理解成要画出每块砖）。V4 接近 V1 的观感但仍比 V1 碎。
- s3 立绘：**所有变体的"膝上构图"指令都没被严格遵守**——12 张里 10 张画成头到脚全身（bbox 高度/画布 ≈0.98-0.99），只有 V3-s2 接近膝盖裁切（0.88）；V0-s1 甚至是 mid-thigh。透明通道本身合格（alpha 0-254，无黑底），但半透边缘环有一圈棕色 fringe（合成到灰底可见），且目检发现左肩/躯干侧有红橙色残边 → 提示词里需要加"clean alpha edge / no color fringe"类约束。[INFERENCE] fringe 来源像是模型先画在黑/深色底上再抠。
- 风格漂移：英文 spec（V2-V4）让立绘更"半写实 painterly"，线条弱化；中文散文（V0/V1/V5）更贴"日式动画线稿"。店主反破碎块没有破坏内容要素（疤、毛巾、裤脚扎带均在）。

## 成本 / 延迟 / revised_prompt

- 36/36 成功；单张 latency 均值 34.5s（24-47s），各变体间无系统性差异。总 token：input 8 670 / output 56 227（output 每张 1337-3168，V4 s3 一张 3168）。
- **`complexity:"low"` 被中继接受**（无任何报错；先以 512² 探针确认）。效果：单独用（V5）≈无感；叠加英文 spec（V4 vs V3）只带来小幅指标改善，远不如反破碎块本身。**不值得为此引入 API 参数分支**；如果非要，它只该作为可选覆盖层。
- **`revised_prompt` 行为**：该中转把 prompt 原样回填（V0/V1/V5 的 revised_prompt = 输入原文，V2-V4 亦为原文含全部标签行），即**不做 OpenAI 式安全改写**。意味着提示词按字面送达，块与标签行都原样生效；也意味着不能指望改写器兜底。（对比官方 gpt-image 会改写——中继语义需记入 API 文档。）
- 尺寸偏差：请求 1536x864，实收 1536x864×11 / 1672x941×6 / 1536x1024×7（V0 两次均为 1536x1024，V5 两张 1024 高 → 偏方的尺寸与"碎/满"程度可能相关，n=2 下无法分离）。

## 结论排名（针对"去破碎感/去 AI 味"，n=2 小样本）

1. **V1（中文散文 + 块原样附加一行）——首选。** 三个主体的边缘密度/碎片/高光/微纹理全部最优或并列最优，内容保真无损失，且语言与小说一致、agent 只需"写散文+固定尾行"，最易做成 skill 约定。
2. **V3（英文标签 spec + Rendering 块）——备选。** 有效但明显弱于 V1；英文 spec 本身（V2）反而比 V0 更碎更 painterly（"灰砖门脸"被逐砖渲染），标签结构对 gpt-image 不构成风格约束。
3. **V4 = V3 + complexity:low——小幅优于 V3，不值得单独走参数通道。**
4. **V2（纯英文 spec）与 V0 同级，且风格偏离"日式动画线稿"。**
5. **V5（只加 complexity:low）≈ V0，无效。**

注意事项：n=2 + 单模型单中继，方向可信、幅度不可信；revised_prompt 原样回填是中继行为，换上游可能不同；立绘膝上构图全员失败（下一轮需在提示词和/或裁切后处理上单独解决）；s1 的 V0 样本碰巧拿到更方的尺寸，部分差距可能含尺寸混杂。

## 建议进入 round 2
- 定型 **"散文描述 + 反破碎块固定尾行"** 为 painter skill 的默认 prompt 结构；把块写入 skills（中英各一版，中文模型下用中文）。
- 立绘 framing 改为在提示词里直接说 "full body visible, head-to-toe" 或改为真正膝上裁切语义并后处理校验（alpha bbox 高度比）。
- 给立绘加 "clean alpha edges, no color fringe, no outline halo" 约束并复检 fringe。
- `complexity` 参数标为"可忽略"；若 round 2 想复测，用 n≥4 且单独变量。
