## 逐臂目视（thumbs/ 与 contact/*.jpg 亲验）

- **B0**（基线）：CG 湿街反光锐利如镜面、墙面微纹理最重（edge .137/spec .0057 最高）；dazayuan 拥挤、碎线多；立绘有红橙杂色描边圈（ring_redbrown 0.99）。水彩风主视觉完全没把风格带过去——style 分 1.15 全场最低。
- **B1**（KV-O+块O）：CG 砖墙哑光、倒影柔和，是“像 KV-O”的一档（style 2.03）。立绘出现白/浅色 halo 描边（非棕红，问题减半）。
- **B2**（KV-P+块P）：CG 与 bg 数值干净（spec 0.0000、svd 0.68-1.36 最低档），评委给的 style match 最高之一（bg 2.62）。但立绘 s1 画成全身+异常低 alpha_cov 0.19，vn 1.35 全场最低——KV-P 的街景参考把立绘带向带背景的小图。
- **B3**（无块）：CG micro .523/edge .114 与 B2 几乎持平，说明**参考图本身就能带大部分风格**；但 bg 明显比 B2 碎（edge .139 vs .103，frag 26480 vs 17694），块在复杂场景仍有增量。
- **B4**（quality medium）：与 B2 差距小，CG edge 反而更差（.135）；评审看到天空色带/压缩感；输入 token 相同、输出 token 少 24%。省钱可接受，画质略降。
- **B5**（+负向行）：数值不差（bg frag 16683 最低档之一），但 fidelity 最低 2.12，一张 CG 内容跑偏（洋车里坐人）。负向行没有明显反噬但也无益——丢弃。
- **B6**（全英）：与 B2 几乎打平，bg svd 最低 0.56。语言对风格基本无影响，但内容忠实度 2.36 与 B7 并列最高（英文内容句无劣势）。
- **B7**（中文散文+中文块，KV-O）：**综合最佳**。micro 0.56 全场最低、CG edge .069、立绘 edge .042 + 无杂色描边（interior_rb 0.69 vs B0 0.99）；评审 frag/micro/ai 三项最优或次优。KV-O 的“照片感微纹理”比 KV-P 弱，配上中文块后画面最净。
- **B8**（同 B7 换英文块）：frag 最低 1.03、ident 最高 2.71，与 B7 几乎同档；块语言影响不大（与第 1 轮“中文块>英文块”的方向一致但不显著，差异主要来自 KV 与 prompt 体，不在块语言）。

## 成本/延迟

- 单次 edit 中位 43.9s，p95 63.3s；臂间无实质差（B3 41.8s 略快、B8 49.4s 最慢，±15%）。
- 54 次 edit 共输入 147k / 输出 92.5k token（每次约 2.7k in/1.7k out，图占大头）；4 次 KV generate 944/6.6k。quality medium 每图约省 300 out token。
- 立绘 alpha：全部 18 张有透明通道，alpha_cov 0.19-0.55；B2-s1 的 0.19 是全身小图异类。bbox_h_ratio 普遍 ~0.99（膝上裁切在多数臂成功——B2-s1 与个别样张仍画全身）。棕红描边：B0 ring_redbrown≈0.99；B1-B8 仍有偏高 ring_redbrown（0.74-0.97），但多为浅白 halo 而非棕红（目视确认），约束文案只解决了一半。

## 结论（排序 + 注意事项）

1. **B7 ≈ B8**（中文散文体 + KV-O 主视觉）：最干净、最贴主视觉、祥子一致性最好。B7/B8 之间块的中英文差异不显著；倾向中文块（与第 1 轮胜者一致，提示词全文中文更利于模型代理仿写）。
2. **B1**（KV-O + 标签格式 + 英文块 O）：英文标签格式里最好；但格式本身无优势（对比 B7 同 KV）。
3. **B2**（KV-P + 块 P）：cg/bg 风格匹配数值最好，但立绘翻车（全身+低 alpha）。
4. **B6** ≈ B4 > B5 > B3。B3 证明参考图能独立带 60-70% 的风格，但块在复杂场景仍压碎边；**不要发负向行**（fidelity 代价）。
5. **B0** 全面最差：水彩风主视觉 + 散文 prompt = 默认 AI 观感 + 红棕描边 + 祥子跨资产认不出（ident 0.86）。

**推荐上线**：生产路径 = KV 作 Image 1 + **中文散文 prompt（含中文参考角色句、中文 M 行）+ 尾行中文渲染块**（即 B7；若团队更愿保留英文块便于维护，B8 同档）。注意三点：

- 主视觉本身要先按目标比例生成/裁剪，否则输出尺寸跟随参考图（本轮 1672x941 大漂移）。
- 立绘参考图最好不是街景：KV 风格是街景时 sprite 的风格匹配/内容稳定度都受损，生产上给立绘臂配角色向主视觉或角色设定图更稳 [INFERENCE：本轮未单独验证角色向 KV]。
- alpha 边缘杂色需在提示词里继续钉（“半透明边像素颜色与邻近衣物/肤色连续”有效但未根除 halo）+ 后处理 unmultiply。

样本量警告：每臂每资产仅 2 样，评分差 <0.15 视为噪声；n=2 下 B7/B8 与 B1 的差距 (~0.2-0.4) 方向可信但幅度不可外推。
