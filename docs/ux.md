# 界面与流程

说明 Novelive 各主要页面与功能入口的交互流程、状态表达和用户控制。

导航方式和主题见 [界面设计指南](../DESIGN.md)；界面原型在 `prototype/`。

## 引导页与书库

- **首次打开**：进入引导页，选择界面语言（简体中文、繁体中文、英文、日文），介绍创作和游玩两条使用路径，并提供模型配置入口（可以跳过）。
- **空书库**：初始书库为空，不放示例作品。不配置模型也能导入 `.novelive` 作品包游玩；配好模型后即可使用创作功能。
- **书库两栏**：书库分为“我的工程”和“导入的作品”两栏。
- **全局制作状态**：侧边栏底部显示全局制作状态（`空闲` / `制作中` / `已停止` / `待确认`），点开可以查看当前队列。
- **作品详情页**：点击书库中的作品卡先进入作品详情页（展示简介、章节列表，以及继续游玩、制作等入口），再从里面进入播放器、制作面板或编辑器。

## 导入向导与两个确认点

- **导入原文**：支持 TXT、EPUB、Markdown、DOCX、PDF。
- **核对向导步骤**：导入后有一个可以直接跳过的向导步骤，用来核对作品信息和章节划分；这一步不算确认点。
- **确认点 1（角色设定 / 主视觉）**：供创作者选定主视觉与角色设定（来自创作者提供的参考图、模型筛选出的 EPUB 插图候选，或无参考时 AI 按书中描写生成的几版设定）。已经有参考图时还停不停，由作品设置里的开关决定。
- **确认点 2（第一章成品）**：第一章制作完成后停下，创作者可以试玩，也可以进入编辑器修改；最后手动点击“继续制作”，其余章节在后台按卷连续制作。

## 制作面板与调度控制

章节面向用户使用四个状态词：**已发布**、**制作中**、**等待**、**需要处理**。章节做完就自动可玩（第一章需先经过确认点 2）。

- **队列与排序**：同一时间只有一部作品在制作，其余作品排队，创作者可以调整排队顺序。
- **章节优先**：在单部作品内部，创作者可以把指定章节设为优先；默认第一章优先，制作按卷推进。
- **立即停止**：停止只有一种方式——立即停止，取消排队任务并中断正在执行的请求；下次继续时，把被中断的任务重新执行一遍。
- **需要处理**：临时错误（网络、限流、服务临时出错）只用 SDK 或 Agent 底座自带的重试，不自己另做重试；失败就停下，标“需要处理”。图片被内容审核拒绝时，先让模型改写提示词再试一次。图片最终失败的章节使用内置占位图（角色、背景、CG 三类）也能玩，并同样标“需要处理”。
- **过期图片**：上游设定集或参考图变化后，受影响的已有图片标为“过期”，由创作者决定重画或保留；同时提示连带关系（例如重画造型基准图时，提示其下的表情是否一起重画）。
- **系统通知**：只在三种情况发送系统通知——停在确认点等待处理、有任务需要处理、整部作品制作完成。（播放器在后台等待本机连载新章时也会发通知。）

## Novelive Agent 面板

创作者在工程里点“Novelive Agent”按钮（或按 Ctrl/⌘+J）打开面板，与 Novelive Agent 讨论创作调整。面板盖在页面右侧，可以全屏；编辑器、设定集会把当前位置带给 Agent。

- 可让 Agent 修改设定集、术语表、改编要求，或发起工作流（重做章节、重写场景、重画图片、重新综合某卷）。
- Agent 提出的所有修改和要发起的工作流都以确认卡列出，写清要做什么、影响哪些章节，创作者确认后才生效。
- 需要重做的章节进入制作队列重新生成。
- 聊天按会话组织：每部作品可以有多个会话，能新建、改名、删除；改写一条消息后重新发送会形成分支，可以在分支之间切换。会话保存在工程中，过长时较早的内容压缩成摘要。
- 面板实时显示 Agent 的回复、可折叠的思考过程、工具调用（参数和结果），以及它派出的子任务；可以随时停止。

## 编辑器能力

编辑器提供以下创作调整能力（不预设界面布局）：

- **直接修改**：直接修改台词和旁白，替换角色表情；修改立即生效，支持撤销并保留修改历史。
- **文本效果**：加、改、删文本标记、注音、句中停顿和变速；在作品设置里创建自定义标记，确认 Agent 提议的新标记。
- **Agent 重写单场景**：让 Agent 重写当前单个场景，结果先以差异列表展示，由创作者勾选后再应用。
- **单张图重生成**：对单张图片发起重新生成，默认出一张直接替换，也可以手动要求多出几张来挑选。
- **保存为规则**：可以把修改存为规则，作用域选定为“本章”或“本作品”（本章规则优先于本作品规则；新规则只影响还没开始的任务）。
- **原文对照**：显示当前场景对应的原文段落，原文和场景支持双向跳转；选中一段原文可以直接让 Agent 按这段内容修改。
- 逐条调整演出的时间线编辑器第一版不做，以后再做。
- **预览**：在编辑器舞台上从当前句往下播放当前场景，可以暂停后修改，改完从这里继续播。正式游玩走播放器。

## 播放器界面控制

播放与演出细节见 [播放器](./player.md)。点“游玩”直接从上次进度进入游戏（不做标题画面），界面是游戏内界面，和创作界面分开。界面控制包含：

- **推进与显示**：文字还在逐字出现或动画未播完时，第一次点击补完这一句，第二次点击进入下一句；支持隐藏界面、调整文字速度和字号。
- **阅读控制**：自动播放、跳过已读、历史记录（可跳回对应位置）、章节目录跳转。
- **存档与回滚**：快速存档 / 读档、普通存档位、跨章回滚。
- **重看规则**：从章节目录打开已读章节时进入“重看”状态，不改变主线进度；主线进度只往前走。
- **本机制作中作品章末行为**：读到最新一章末尾时，显示下一章制作进度；若一直停留在播放器界面，下一章做完后自动载入开头并等待玩家点击；应用处于后台时发送系统通知。
- **系统菜单**：Esc 或右键打开，有存档、读档、设置、记录、章节和返回作品页；自己工程的作品多一项“在编辑器中打开这里”。

## 设置与用量统计面板

- **设置**：包含五个模型配置（快速、主模型、写作、视觉、图片）、API Key、界面语言和默认工程位置；高级设置里可以单独给某个 Agent 角色换模型，还有全局默认写手预设。文本模型填接口格式（OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 三选一）、接口地址、模型名、上下文长度和 API Key，经 Agent 底座调用；图片模型只接 OpenAI 兼容图片接口并可填自定义地址。API Key 简单加密后存在应用的配置文件中，方便备份和迁移。
- **用量统计面板**：按作品、阶段、模型、时间（天 / 月）统计调用与消耗，能拿到单价时显示参考金额。用量仅作参考，不设预算，不做开工前估算，也不会触发自动停止。

## 导入、更新、导入为工程与导出

- **工程文件夹**：新建作品时由创作者选择存放位置（默认在 `文档/Novelive` 下），整个文件夹拷贝即可跨机器迁移。
- **导入作品**：导入的 `.novelive` 文件复制一份到默认工程位置旁的「导入的作品」文件夹（默认 `文档/Novelive/导入的作品`），原文件删了也能玩。
- **版本更新**：作品包带有版本号。玩家导入同一作品的新版本 `.novelive` 时先提示，确认后替换旧版；存档和已读记录按 ID 迁移，对不上的旧存档保留。
- **导入为工程**：已导入的 `.novelive` 作品包可以导入为新工程继续编辑；再次导出时成为一部新作品，并在包内记录它来自哪部作品。
- **导出**：将工程中可分享部分打包为 `.novelive` 文件。导出范围可选单部作品、整卷或整个系列；是否包含原文可选，默认不带。若导出范围包含使用占位图（“需要处理”）的章节，导出时列出这些章节提醒创作者，但不阻止导出。

## 托盘、退出与崩溃恢复

- **关闭窗口**：关闭主窗口后应用缩到系统托盘，后台制作继续运行。
- **退出应用**：执行真正退出时，如果仍有制作任务在运行，询问创作者后再决定是否退出。
- **崩溃或异常退出**：应用异常退出后重新打开时，制作保持停止状态，由创作者确认后才继续。
