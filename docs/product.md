# Novelive 产品概述

说明 Novelive 的定位、用户、平台、核心流程、第一版范围、后续与不做事项、里程碑及待定项。

## 定位、用户与平台

- **定位**：Novelive 是 Electron 桌面应用，用于把小说改编为视觉小说并直接游玩。创作 Agent 叫 **Novelive Agent**（简称 Agent）。
- **用户**：首要用户是创作者 / 搬运者，将小说制作并打磨后导出为 `.novelive` 作品包分享；玩家与创作者使用同一个应用，不配置模型也能导入作品包游玩，配好模型后即可启用创作功能。
- **平台与协议**：支持 Windows、macOS、Linux；开源协议为 AGPL-3.0；界面语言支持简体中文、繁体中文、英文、日文。
- **分享方式**：作品只通过文件分享。不做在线平台，不记录也不展示版权或署名信息。

## 核心流程

1. **导入与向导**：导入本地原文（TXT、EPUB、Markdown、DOCX、PDF）。导入后有一个可以直接跳过的向导步骤，用来核对作品信息和章节划分，不算确认点。
2. **全书预览与按卷综合**：用快速模型逐章读完正文（超长章节切段预览，不截断），再按卷综合产出剧情骨架、设定集与术语表；第一卷的预览和综合完成就开始制作，后面各卷在后台继续。
3. **确认点 1（角色设定 / 主视觉）**：由创作者选定或确认第一卷主要角色的设定与主视觉；其余角色第一次出场时直接画，不停下。已经有参考图时是否停下，由作品设置里的开关决定。
4. **第一章成品与确认点 2**：第一章做完后停在第二个确认点，创作者可以试玩，也可以进编辑器修改，最后手动点“继续制作”，其余章节在后台按卷连续制作。
5. **游玩、编辑与导出**：章节做完自动可玩（第一章需先过确认点）。创作者可以在编辑器修改，并导出 `.novelive` 作品包。

详见 [界面与流程](./ux.md) 与 [创作流程](./creation-pipeline.md)。

## 第一版范围

| 方面 | 第一版包含 |
| --- | --- |
| 原文与结构 | TXT、EPUB、Markdown、DOCX、PDF；支持长篇，保留 `系列 → 卷 → 作品 → 章节` 层级 |
| 理解与改编 | 全书预览与按卷综合；候选设定冲突时不覆盖已确认设定；两组三档预设（改编强度、演出密度）、作品级改编要求、本章 / 本作品规则；直出目标语言剧本与术语表 |
| 视觉素材 | `角色 → 造型 → 表情`、`地点 → 变体`、CG；可复用与一次性角色；透明底直出；背景变体从基准图派生；16:9 加安全区、横屏铺满裁切；Python 放大降噪（默认 2K，可选 4K）；WebP 有损 / 无损存储；技术检查；过期标记 |
| 制作调度 | 同一时间制作一部作品，多作品排队排序；作品停在确认点时让出制作槽，确认后排回队首；作品内章节优先；第一章优先；写剧本和出图重叠，出图队列按素材去重、基准图先于差分；立即停止；占位图降级发布（“需要处理”）；托盘运行与崩溃后停止恢复 |
| 编辑器 | 直接修改台词旁白、编辑文本标记 / 注音 / 句中停顿与变速、Agent 重写单场景（差异列表勾选）、单图重生成、换表情、保存规则、撤销与修改历史、原文对照与双向跳转 |
| 播放器 | 背景 / 立绘 / CG / 前景 / 镜头 / 粒子 / 遮罩与滤镜演出；对白 / 内心独白 / 旁白 / 字幕四种文本，文本标记与作品自定义标记、注音、句中停顿与变速；自动播放、跳过已读、历史跳回、隐藏界面、文字速度与字号、快存 / 普通存档、跨章回滚、目录重看；本机制作中作品章末等待与自动载入 |
| 格式与工程 | 单一语义化格式（加载时现场编译）；工程文件夹；导出单部 / 整卷 / 整个系列（默认不带原文）；作品包导入为工程；版本更新保留并按 ID 迁移存档；同系列共享与覆盖 |
| 模型与用量 | 快速、主模型、写作、视觉、图片五个模型，可按九个 Agent 角色单独换；写手预设（全局默认 + 作品选用）；图片走 OpenAI 兼容接口，出图并发（同时出图数，默认 8）和失败重画（默认 3 次）可设；用量统计面板（只作参考，不设预算与估算，不自动停机） |

## 以后可能做与不做

- **以后可能做**：Android 版；分支剧情、好感度、多结局；联网搜参考图；逐条调整演出的时间线编辑器；BGM、音效、TTS。
- **明确不做**：网页播放器；骨骼动画和 Live2D；在线平台；记录或展示版权与署名信息。

## 里程碑

采用界面先行路线。界面设计先定下来再写代码；从 M1b 起，每个里程碑结束时都能在应用里用一本真书走一遍（M1a 用真书产出能在磁盘上检查的工程文件夹）。

| 里程碑 | 内容 |
| --- | --- |
| 界面设计 | 视觉方向、导航方式、主题、图标，以及主要界面的原型 |
| M0 骨架 | Electron 外壳、创作端后台进程、IPC 与自定义资源协议、浏览器开发模式、五块代码的目录、TypeBox、SQLite 选型核实、接通 pi 1.x 和图片接口、录制回放的假服务 |
| M1a 工程与理解 | 作品格式、剧本语法与解析器（含剧本检查与局部修复）、导入 TXT、全书预览、按卷综合；产出能在磁盘上检查的工程文件夹 |
| M1b 最薄的完整链路 | 两个确认点 → 逐章写剧本、审稿、演出与出图（画师分工、出图队列、同义表情合并）→ 最小播放器（背景、立绘、四种文本、点击推进）→ 制作面板；调度只做单作品、章节优先、立即停止；质量评测集；用真书走完整条链路 |
| M2 编辑器与 Agent 对话 | 改台词、换表情、Agent 重写场景、单图重生成、规则、撤销与修改历史、原文对照、对话面板、设定集和术语表的查看与确认 |
| M3 播放器补全 | 镜头、CG、前景、粒子、遮罩滤镜、文本标记与自定义标记、注音、停顿变速、自动播放、跳过已读、历史跳回、存档读档、跨章回滚、目录重看、章末等待；横屏各比例版面适配；放大降噪（Python 进程）；在 Linux 上试打一次安装包并跑通 |
| M4 长篇与调度补全 | 系列 / 卷 / 作品三层与覆盖、多卷连续制作、EPUB / Markdown / DOCX / PDF、多作品排队、托盘、崩溃恢复、系统通知、用量统计、跨语言制作、过期标记 |
| M5 分享与发布 | 导出、导入为工程、版本更新与存档迁移、三平台安装包和自动更新；在此之前只在开发模式下跑、只测 Linux（M3 的 Linux 试打包除外） |
