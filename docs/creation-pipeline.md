# 创作流水线

说明小说从导入、全书理解、剧本改编到调度、停止恢复与编辑修改的完整流程。

## 1. 导入与全书理解

原文支持 TXT、EPUB、Markdown、DOCX、PDF，工程内保留 `系列 → 卷 → 作品 → 章节` 层级，支持数百上千章的长篇作品（工程结构见 [工程与作品格式](./work-format.md)）。

导入后有一个可以直接跳过的向导步骤，用于核对作品信息和章节划分，这一步不算确认点。

正式制作前，用快速模型完成**全书预览**，逐章读完全部正文。每章产出剧情摘要、出场人物、地点、时间线线索和伏笔；超长章节切段预览，不截断。

综合与制作都按卷推进，第一卷理解完就可以开始制作该卷。综合按卷产出剧情骨架、设定集和术语表（字段见[设定集与术语表](./bible.md)）。新提取的设定条目先作为候选，不冲突的直接用于制作；和已确认的设定冲突时不覆盖，制作继续用已确认的版本，冲突等创作者处理，不阻塞制作。

## 2. 确认点

创作过程中只有两个确认点：

1. **角色设定 / 主视觉**：确定主要角色与视觉参考（详见 [视觉管线](./visuals.md)）。已经有参考图时是否停下确认，由作品设置里的开关决定。
2. **第一章成品**：创作者可以试玩，也可以进编辑器修改；手动点击“继续制作”后，其余章节在后台按卷连续制作。

## 3. 改编控制与原则

创作者通过两组三档预设、自由文本和规则控制改编结果：

| 控制项 | 选项与默认值 | 作用域与规则 |
| --- | --- | --- |
| 改编强度 | 忠实 / 平衡（默认）/ 精简 | 作品级预设 |
| 演出密度 | 宽松 / 标准（默认）/ 激进 | 作品级预设 |
| 改编要求 | 自由文本 | 作品级设定 |
| 规则 | 在编辑时把修改存为规则 | 作用域为本章或本作品；本章规则优先于本作品规则，新规则只影响还没开始的任务 |

改编遵循以下原则：

- 保留对白原意和口吻。
- 动作和表情转成演出。
- 长段环境描写压成短旁白，必要的旁白保留。
- 不加原作没有的情节。

改编时模型可以给文字加文本标记、注音、句中停顿和变速（文本能力见[播放器](./player.md)）。模型也可以提议新的自定义标记，创作者确认后才生效。

跨语言制作只走“直接生成目标语言剧本”这一条路，术语表负责统一人名、地名等译法。

## 4. 调度、停止与恢复

### 4.1 队列与章节推进

- **单作品队列**：同一时间只有一部作品在制作，其余作品排队，可以调整顺序。
- **章节优先**：第一章优先制作；作品内部，创作者可以把某几章设为优先。
- **单章流程**：每章先分场景，再逐场写剧本；图片在依赖就绪后并行生成（视觉规则见 [视觉管线](./visuals.md)）。
- **章节完成与占位图**：章节做完就自动可玩（第一章要先过确认点）。图片最终失败的章节用占位图也能玩，并标“需要处理”。占位图分三类：角色、背景、CG。导出 `.novelive` 作品包时会列出这些章节提醒创作者，但不阻止导出。

### 4.2 停止、错误与退出恢复

- **立即停止**：停止只有这一种方式，会取消排队任务并中断正在跑的请求。下次继续时，把被中断的任务重新执行一遍。
- **临时错误**：遇到网络、限流或服务临时出错时，只用 SDK 或 Agent 底座自带的重试，不自己另做重试；失败就停下，标“需要处理”。
- **图片被内容审核拒绝**：不算临时错误。让模型把提示词改得含蓄一点再试一次，还被拒才用占位图，标“需要处理”。
- **关闭与退出**：关窗口后缩到托盘，制作继续；真正退出时如果还有任务在跑，询问创作者。
- **崩溃恢复**：崩溃或异常退出后重新打开，制作保持停止状态，创作者确认后才继续。
- **系统通知**：只在停在确认点等待处理、有任务需要处理、整部作品做完这三种情况发送。

## 5. Novelive Agent 与对话面板

创作由 **Novelive Agent** 驱动，Agent 底座用 pi。

作品级对话面板支持创作者与 Agent 讨论，让 Agent 修改设定集、术语表、改编要求，或重做指定章节：

- Agent 提出的所有修改先列给创作者，确认后才生效。
- 重做的章节进入制作队列。
- 聊天记录保存在工程里，Agent 能参考之前聊过的内容。

## 6. 模型配置与用量统计

创作者自己准备三类模型：**快速模型**（用于全书预览）、**创作模型**和**图片模型**，默认这些模型都有多模态能力。

- 图片模型只接 OpenAI 兼容的图片接口，可以填自定义地址。
- 文本模型填接口格式（OpenAI Chat Completions、OpenAI Responses、Anthropic Messages）、接口地址、模型名和 API Key，通过 Agent 底座调用。
- API Key 简单加密后存在应用的配置文件里，方便备份和迁移。

用量统计面板按作品、阶段、模型和时间（天 / 月）统计，能拿到单价时显示参考金额。统计结果只作参考，不设预算，不做开工前估算，也不会自动停止。

## 7. 编辑器背后的修改

创作者可以在编辑器中修改已生成的内容（界面与交互见 [界面与流程](./ux.md)）：

- 直接修改台词和旁白，或替换角色表情。
- 让 Agent 重写单个场景，结果先以差异列表展示，勾选后再应用。
- 原文对照显示当前场景对应的原文段落，原文和场景可以双向跳转；选中一段原文可以直接让 Agent 按它改。
- 单张图重新生成，默认出一张直接替换，也可以手动要求多出几张来挑。
- 把修改存为规则。

修改立即生效，可以撤销，有修改历史。逐条调整演出的时间线编辑器以后再做。
