# 视觉管线

说明视觉素材的层级组织、参考来源、生成要求、技术检查、占位图与过期重生成规则。

## 1. 素材层级

视觉素材分为三类：

- **角色**：`角色 → 造型 → 表情`
- **地点**：`地点 → 变体`
- **CG**：单独一类

同一系列的作品可以共享素材，下级的卷或作品可以覆盖（详见 [工程与作品格式](./work-format.md)）。不做骨骼动画和 Live2D。

## 2. 角色、参考来源与确认点

### 2.1 角色分类与立绘规范

- **可复用与一次性角色**：角色分为可复用角色和一次性角色。可复用角色先建完整参考，长期复用；一次性角色只画当前场景要用的，之后再出场时升级为可复用角色。
- **立绘构图与对齐**：立绘画膝上或半身，按头顶或腰线对齐。
- **表情**：新建角色时先登记一套基础表情，模型写剧本时用到新表情就直接登记；表情第一次在剧本里用到时才画（见[设定集与术语表](./bible.md)）。
- **角色一致性**：（待定：角色长相一致的做法采用母图加图片编辑派生，还是每张单独生成并带参考图，搭骨架时试过模型再定）。

### 2.2 参考来源与确认点

参考来源分三种，不做联网搜图（以后可能做）：

1. 创作者提供的参考图。
2. EPUB 插图：由模型筛选后，作为候选放进“角色设定 / 主视觉”确认点。
3. AI 生成：没有参考时，AI 按书中描写出几版角色设定供创作者挑选。

“角色设定 / 主视觉”是制作流程的第一个确认点（见 [创作流水线](./creation-pipeline.md)）。已经有参考图时是否停下确认，由作品设置里的开关决定。

## 3. 生成规则与本地处理

- **透明底**：立绘的透明底由图片模型直接输出，不做色键抠图。
- **背景变体**：同一地点的变体（白天、夜晚、雨天）从该地点的基准图编辑派生。
- **画面内文字**：招牌、信件等画面里的文字由图片模型直接画，不做文字识别校验。
- **放大与降噪**：放大和降噪由一个 Python 进程负责；转无损 WebP、缩放、缩略图等其他图片处理在创作端进程里完成（进程划分见[系统架构](./architecture.md)）。

## 4. 技术检查与占位图

技术检查只看四项，不做审美检查：

- 能否解码
- 尺寸是否正确
- 主体是否完整
- 透明底是否有效

图片最终失败的章节用占位图也能玩，并标“需要处理”。占位图分三类：**角色**、**背景**、**CG**。导出 `.novelive` 作品包时会列出这些章节提醒创作者，但不阻止导出。

## 5. 单图重生成与过期提示

- **单图重生成**：在编辑器中可以重新生成单张图片，默认出一张直接替换，也可以手动要求多出几张来挑。
- **过期与连带提示**：上游设定或参考图变化后，受影响的图片标为“过期”，由创作者决定重画还是保留。重画上游素材时会提示连带关系，例如重画造型基准图时，提示它下面的表情要不要一起重画。剧情里的外貌变化不算上游变化，而是开新造型（见[设定集与术语表](./bible.md)）。
