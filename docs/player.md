# 播放器

说明 Novelive 播放器的运行方式、演出与文本能力、推进控制、进度状态以及更新迁移行为。

## 运行方式

- **只读读取**：播放器以只读方式读取导入的 `.novelive` 作品包或本机工程中的可玩章节，不修改原文件。
- **加载时编译**：作品包中存语义化剧本、设定集、术语表和分层素材（见[作品格式与工程](./work-format.md)），播放器加载时现场编译。
- **不依赖模型与创作端**：玩家和创作者使用同一个应用，不配置模型也能导入作品包游玩，播放过程不调用模型，播放器也不依赖创作端。

## 演出与文本

### 舞台比例

- 舞台以 16:9 为基准；背景和 CG 生成时主体落在中间的 4:3 安全区（见[视觉管线](./visuals.md)）。
- 各种横屏比例（16:10、4:3、手机横屏、21:9）统一铺满窗口、裁掉多出的部分，不留黑边；不做竖屏。

### 演出能力

- 背景切换和过渡
- 立绘上场、退场、移动、换表情、换造型
- CG、前景层
- 镜头对焦、缩放、震动
- 粒子、遮罩和画面滤镜

### 文本

**文本类型**有四种：

- **对白**：角色说出口的话，显示说话人名字。
- **内心独白**：角色心里想的话，显示名字，样式和对白区分开。
- **旁白**：叙述者的话，不显示名字。
- **字幕**：不进文本框，单独显示在画面上，比如时间地点卡、章节标题。

每句话可以单独指定显示名（比如身份揭晓前的“神秘少女”“???”），内部仍认作同一个角色。

**文本标记**是一句话里局部文字的效果。内置七种：强调、加粗、弱化、小声、大喊、扭曲、高亮。作品还可以自定义标记，样式由作品自己定义。

**注音**：在字的上方标读音或原名，比如日文汉字上标假名、译名上标原名。

**停顿与变速**：一句话中间可以停顿，某几个字可以出得更快或更慢。

- 停顿或慢速出字时点击，直接补完整句。
- 自动播放照常停顿和变速；跳过已读忽略它们。

## 推进与控制

### 点击推进

文字还在逐字出现或动画没播完时，第一次点击补完这一句，第二次点击才进入下一句。哪些位置等点击由剧本决定（见[作品格式与工程](./work-format.md)的“推进节奏”）。

### 控制项

- 自动播放
- 跳过已读
- 历史记录（可以跳回）
- 隐藏界面
- 文字速度和字号
- 快速存档 / 读档
- 普通存档位
- 回滚（可以跨章）
- 章节目录跳转

## 进度与特殊章节

### 存档位置

存档和已读记录统一放在应用数据目录，按作品 ID 分开，自己工程里的作品也一样。导出作品不会带上存档，作品更新时也只在这一处迁移。

### 重看与主线进度

从章节目录打开已读过的章节时进入“重看”状态，不改变主线进度；主线进度只往前走。

### 制作中作品的章末行为

本机还在制作的作品，读到最新一章末尾时：

- 显示下一章的制作进度。
- 如果一直停在播放器，下一章做完就自动载入开头，等玩家点击。
- 应用在后台时发系统通知。

### 需要处理章节

图片最终失败的章节标为“需要处理”（见[创作流水线](./creation-pipeline.md)），使用三类占位图（角色、背景、CG）也能游玩。

## 更新后存档迁移

作品包有版本（见[作品格式与工程](./work-format.md)）。玩家导入同一作品的新版本时先提示，确认后替换旧版，存档和已读记录按 ID 迁移，对不上的旧存档保留。

## 暂不做与以后可能做

- **以后可能做**：BGM、音效、TTS 第一版不做，以后可能加；分支剧情、好感度、多结局以后可能加。
- **不做**：网页播放器、骨骼动画和 Live2D。
